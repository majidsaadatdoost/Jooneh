# Provenance and calculation notes

Public catalog only. These files contain no user data and the build script never connects to the journal database.

## Direct reference foods

99 displayed entries use USDA FoodData Central **SR Legacy, final April 2018 release**. This is a broad historical reference dataset, not a claim to be the latest laboratory analysis of an Iranian food or brand. Values were extracted from the official JSON archive on 2026-10-18, not scraped from a calorie website or generated by a language model.

- Download index: https://fdc.nal.usda.gov/download-datasets/
- Official archive: https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_sr_legacy_food_json_2018-04.zip
- Archive SHA256: `0fe8ae486a2c8eb42cb96413f058deb51863a46c8fb8eeb4b1fb45006dd338ef`
- Documentation: https://fdc.nal.usda.gov/data-documentation/
- USDA data are public domain: https://fdc.nal.usda.gov/faq/

`usda-selected.json` contains 108 referenced records, including ingredients used only by recipes. Each record retains the exact original description and FDC ID. Nutrient IDs: 1008 energy (kcal), 1003 protein, 1005 carbohydrate by difference, 1004 total lipid, 1079 dietary fiber, 2000 total sugars (all grams). Missing amounts remain null, never inferred as zero. Sugar is part of carbohydrate; fiber may also be included in carbohydrate by difference. We use USDA energy, not a second sum of these overlapping fields.

`foods.tsv` maps each displayed Persian name to an explicit FDC record, edible gram weight, and display unit. The formula is **amount per 100 g × grams in the displayed portion ÷ 100**. Values retain two decimal places internally; UI rounds to one decimal. Only the egg uses a count unit, with a declared 50 g edible portion. Milk and coffee are deliberately in grams; no undeclared conversion from grams to millilitres. Nut and seed weights exclude hard shells. Cooking state is included in the name or note. Generic US packaged foods must not be represented as verified Iranian brands.

## Iranian dishes

24 entries are **Jooneh recipe estimates**, not measured national reference values. The Iranian Food Composition Table 2017 is listed by EuroFIR as not publicly accessible outside FoodEXplorer: https://www.eurofir.org/food-information/food-composition-databases/

Each recipe in `recipes.json` declares all modeled ingredient weights, exact ingredient FDC IDs, and assumed final edible weight. The formula is **sum(ingredient per-100-g value × ingredient grams / 100) × 100 / final dish grams**. Missing ingredient nutrients propagate to null. We predominantly use cooked meat/grain/legume records, and count added oil explicitly; some vegetables/herbs are raw as declared. No measured cooking yield, retention factor, fat drainage, water reduction, or restaurant portion is asserted. These recipes are nutrient models, not authoritative culinary recipes. For example, the koobideh model uses a cooked ground-beef reference plus cooked onion; the real fat content and cooking losses can differ substantially. Cooked whole egg is the proxy for egg in omelette, kuku and tahchin. Rice, bread and other accompaniments are excluded unless listed.

The app displays the estimate label, full ingredients, final weight, and links. Users should edit or copy a recipe estimate to match the food they actually eat; a familiar dish name alone cannot identify exact nutrition.

## Retained legacy foods

Four existing catalog entries remain clearly identified as estimates or user-supplied, unverified values: sangak bread, breaded fish, Kaleh skyr and Kaleh protein ice cream. Do not describe these as USDA-verified. Package labels take priority for branded products.

## Rebuild

```sh
python scripts/build-foods.py
node tests/catalog-client.mjs
```

The generated `docs/assets/reference-foods.js` contains only the selected public records and modeled recipes. No network request is needed to search the food catalog. Stable legacy food IDs keep favorites working. Journal entries store snapshots; updating this catalog does not rewrite them. No database migration or startup write is part of this release.
