# جونه 🌱

دفترچه غذایی فارسی، فونت وزیر، ثبت وعده‌ها و خوراکی‌های اختصاصی، دستورهای ساده و باغچه انگیزه.

## وضعیت فعلی

کد نسخه مستقل برای GitHub Pages آماده شده است. **اتصال Supabase هنوز تنظیم نشده؛ ورود و ذخیره آنلاین این نسخه تا تکمیل مراحل زیر فعال نیست.** نسخه قبلی Sites جداگانه باقی می‌ماند. هیچ دفترچه شخصی یا رمز حسابی در این ریپازیتوری نیست.

## اطلاعات کجا ذخیره می‌شوند؟

- GitHub و GitHub Pages: فقط کد و فایل‌های عمومی سایت.
- Supabase Auth: ورود با ایمیل و رمز، بازیابی رمز و مدیریت نشست.
- Supabase Postgres: دفترچه و تاریخچه خصوصی هر حساب. داده‌ها در مرورگر یا ریپازیتوری نگهداری نمی‌شوند. مرورگر فقط نشست ورود را نگه می‌دارد.
- تأیید ذخیره با پیام «آنلاین ذخیره شد» است. تغییر آفلاین تا دریافت تأیید، ذخیره قطعی نشده است.

## راه‌اندازی با حساب مالک

1. در Supabase یک پروژه متعلق به خودتان بسازید/انتخاب کنید. فعال‌سازی پروژه و پلن باید با اطلاع مالک انجام شود.
2. فایل `supabase/001_jooneh.sql` را یک بار در SQL Editor اجرا کنید. این فایل جدول‌ها، تاریخچه و توابع حساب‌محور را می‌سازد. جدول‌ها در schema خصوصی، بدون دسترسی مستقیم کاربران هستند؛ توابع فقط شناسه کاربر تأییدشده را مبنا می‌گیرند.
3. در Auth، ورود Email/Password را فعال و **ثبت‌نام عمومی را غیرفعال** کنید. حساب‌های مجاز را خودتان از بخش Users ایجاد کنید. رمز را در چت یا ریپازیتوری ننویسید.
4. Site URL و Redirect URLs را روی `https://majidsaadatdoost.github.io/Jooneh/` تنظیم کنید. برای بازیابی رمز، تنظیمات ارسال ایمیل پروژه را بررسی کنید.
5. در `docs/config.js` فقط Project URL و **publishable key** را وارد کنید. این کلید برای مرورگر است و باید با محدودیت‌های SQL همراه باشد. **هرگز secret key، service_role key، رمز دیتابیس یا توکن گیت‌هاب را وارد نکنید.**
6. در GitHub → Settings → Pages، گزینه **Deploy from a branch**، شاخه `main` و پوشه `/docs` را انتخاب و ذخیره کنید.
7. ورود، بازیابی رمز، ذخیره، بارگذاری از دستگاه دوم و جداسازی دو حساب را در پروژه واقعی آزمایش کنید. اتصال و سیاست‌های نسخه زنده هنوز در این ریپازیتوری تأیید نشده‌اند.

## انتقال ثبت‌های نسخه قبلی

در نسخه قدیمی، از تنظیمات «دریافت پشتیبان» بزنید. پس از راه‌اندازی نسخه جدید، با حساب صاحب دفترچه وارد شوید و فایل را با «بازیابی پشتیبان» وارد کنید. این انتقال داده خصوصی است؛ فایل پشتیبان را در GitHub عمومی بارگذاری نکنید. مهاجرت خودکار بین حساب ChatGPT و حساب جدید انجام نمی‌شود.

## دوام داده‌ها

داده‌ها با پاک شدن مرورگر حذف نمی‌شوند. هر روز جدا ذخیره می‌شود و تاریخچه بازنویسی‌ها برای بازیابی باقی می‌ماند. هیچ کد حذف خودکار دوره‌ای در این برنامه وجود ندارد. ماندگاری همیشگی قابل تضمین نیست؛ پروژه، حساب سرویس و نسخه پشتیبان مستقل را نگهداری کنید. محدودیت‌ها و شرایط پلن سرویس را هنگام انتخاب بررسی کنید.

## توسعه

سایت بدون مرحله build از `docs/` اجرا می‌شود. `docs/assets/app.js` رابط اصلی و صف ذخیره با کنترل نسخه است. `auth.js` از SDK رسمی Supabase استفاده می‌کند. فونت وزیر و کتابخانه ورود در همین ریپازیتوری هستند.

بررسی syntax: `node --check docs/assets/app.js` و `node --check docs/assets/auth.js`.

مقادیر غذایی تخمینی‌اند؛ هدف کالری خودکار فعال نیست. «غذای خودم» برای ورود اطلاعات بسته‌بندی استفاده می‌شود.
